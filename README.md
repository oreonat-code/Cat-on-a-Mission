# Team 8

React (Vite) + Express + Postgres (Supabase).

## Setup
1. Create a Supabase project, then run `schema.sql` in its SQL editor.
2. `cp server/.env.example server/.env` and fill in `SUPABASE_URL` and `SUPABASE_SERVICE_KEY`.
3. `npm run install:all`
4. `npm run dev` — client on http://localhost:5173, API on http://localhost:5000
